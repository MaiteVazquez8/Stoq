# Stoq

Sistema de gestión de stock diseñado para facilitar la administración y el control de productos de un negocio. Su objetivo es centralizar la información del inventario, mantener actualizadas las existencias y simplificar el registro de entradas y salidas de mercadería.

El sistema busca reducir los errores de los registros manuales, mejorar la organización de los productos y brindar información confiable para facilitar la toma de decisiones.

### Tecnologías

- Vue.js
- Supabase

### Objetivo

Ofrecer una herramienta sencilla, organizada y eficiente para gestionar inventarios de manera digital.
